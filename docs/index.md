# Welcome to PowerOps SDK

PowerOps SDK is a domain-specific SDK for interacting with Cognite Data Fusion (CDF) for the power operations domain.

PowerOps must be deployed and configured for the CDF project before using this SDK.

## Main Features

- `cognite.powerops.client.PowerOpsClient` for domain-focused interactions with CDF.
- Resource Sync (`resync`) through the `powerops` CLI for configuration synchronization.

## What You Will Find Here

- **Installation**: package install instructions and basic configuration references.
- **Quickstart**: client initialization examples with YAML and existing Cognite client.
- **Setup**: project setup prerequisites for new PowerOps projects.
- **Resync**: config-sync and purge workflow references.
